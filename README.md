# Delhi Busana - Landing Page

Luxury landing page and digital catalog for traditional Indonesian clothing (Busana Adat).

## Features
- **Luxury Aesthetic**: Deep Maroon & Gold premium design.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Fast Performance**: Images optimized in WebP format.
- **WhatsApp Integration**: Direct order via floating button.

## How to Run Locally
1. Clone this repository.
2. Open `index.html` in your browser, or:
3. Run `npm start` (requires Node.js and live-server).

## Project Structure
- `index.html`: Main page.
- `assets/css/`: UI styling.
- `assets/js/`: Interactive logic.
- `assets/images/`: Product catalog images (WebP).
